# Всходы — альфа 0.2

Нажмите на баланс над полем, чтобы открыть коллекцию. Вкладка культур отслеживает собранный урожай и бонус к продаже. Новые виды открываются в пакетах. Во вкладке наборов показаны настоящие наборы из четырёх культур, их состав и материал; другие вкладки — свойства и особые предметы. Ненайденные предметы серые; подсказки материалов объясняют их назначение. После первой находки появляется описание и счётчик запаса.

## Новые награды
Каждый обычный плод даёт одну награду: орбы, материал набора или материал свойства. Сам плод остаётся в корзине. Кристалл дублирования выпадает отдельно с шансом 0,01%. Гибриды новые ресурсы не добывают.

| Редкость | Орбы / набор / свойство | Орбов |
|---|---|---|
| Обычная | 98 / 1 / 1% | 1 |
| Редкая | 97 / 1,5 / 1,5% | 4 |
| Эпическая | 96 / 2 / 2% | 16 |
| Легендарная | 90 / 5 / 5% | 64 |

## Усиления
Откройте «Усиление гибридов» справа, нажмите «Выберите гибрид» и выберите его в инвентаре. Там же можно оказаться из карточки гибрида. Попытка расходует один соответствующий материал. Успех добавляет 1% усиления, неудача снимает один уровень. Врождённые свойства не теряются. Максимум +100%, шанс успеха начинается с 99% и не опускается ниже 45%.

1500% (+1%) означает фактические 1515%. Потомок наследует только врождённую силу. Усиление предметами переносится между линиями через кнопку свойства: источник теряет передаваемый бонус. Если у получателя уже есть бонус, усиления меняются местами без потери уровней. Обе линии нужно собрать с грядок.

## Стартовый баланс
- Рост ускоряется в 1,01 раза за уровень. Половина времени — примерно 70 уровней.
- Через каждые 10 покупных уровней нужен барьер за волокно; стоимость 1, 2, 4… Отдельно для каждой культуры и характеристики.
- После первых 10 уровней к цене в монетах добавляются орбы.
- Концентрат улучшает экстрактор, активный экстракт открывает автоматизации, ядро продлевает сеанс орошения.
- Дублирование материалов находится в «Улучшения → Инструменты».

В отладке можно добавить орбы клавишей Enter и получить по 100 всех материалов для проверки. Для обычной игры эти кнопки не нужны.

Плантации, теплица, уровень игрока, деревья и сезоны в эту версию не входят. Существующие сохранения сохраняются.

## Последние изменения
Коллекция урожая: 10, 20, 40, 80… плодов, +1% к цене за уровень. Для набора нужен минимум один плод каждого вида. Покупка семян: удерживайте карточку для ускорения до 10000/с или наведите на неё и введите точное количество во всплывающем окне.

## Уточнения после тестов
Барьеры открывают ещё 100 уровней (первый предел — 10). В магазине семян показан текущий запас. Подсказки и покупка держатся внутри окна. Сбор коллекции отображается как 131/160. Монеты округляются вверх. Удаление находки — два быстрых нажатия. Док раскрывается за 0,2 с и открывает инвентарь одним кликом. В отладке есть выдача конкретного материала.
