# Изображения культур

PNG с прозрачностью, 256×256 пикселей. В каждой папке пять файлов:

- packet.png — пакетик семян.
- stage-1.png — посаженное семечко.
- stage-2.png — росток.
- stage-3.png — подросшее растение.
- stage-4.png — готовая культура, также иконка урожая.

Не добавляйте текст и рамку внутрь изображения. Для всех стадий сохраняйте одинаковую точку опоры у земли. Можно добавлять файлы постепенно. После добавления обновите страницу браузера, пересборка не нужна.

Папки соответствуют культурам в порядке каталога: radish — редис, lettuce — салат, zucchini — кабачок, peas — горох, beetroot — свёкла, onion — лук, garlic — чеснок, potato — картофель, carrot — морковь, cucumber — огурец, tomato — томат, bell-pepper — перец, eggplant — баклажан, cabbage — капуста, cauliflower — цветная капуста, celery — сельдерей.
