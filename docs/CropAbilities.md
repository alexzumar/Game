# Способности культур — проект

Это предложения для будущего соседства. В текущей игре действует собственное отрастание картофеля и свойства линий. Пространственные ауры ниже ещё не включены. Числа предварительные, не являются агрономическими нормами.

| Культура | Область | Игровая способность |
|---|---|---|
| Редис | Крест, 4 клетки | При сборе продвигает рост соседей на 3% их полного таймера. Быстрый урожай запускает короткие импульсы. |
| Листовой салат | Диагонали, 4 клетки | Сохраняет влагу соседей на 10% дольше. Образ небольшого почвенного покрова. |
| Кабачок | Вокруг, 8 клеток | Уменьшает расход влаги соседей на 15%. Образ широких затеняющих листьев. |
| Горох | Крест, 4 клетки | После сбора оставляет соседям +10% скорости на один цикл. Вдохновение — азотфиксация и влияние растительных остатков. |
| Свёкла | Та же строка | Каждый четвёртый сбор соседнего растения даёт +1 урожая. Игровой образ запасания питательных веществ. |
| Лук | Вокруг, 8 клеток | +10% к будущей защите соседей от стресса. Аромат как игровая тема. |
| Чеснок | Крест, 4 клетки | Усиливает численные эффекты соседских аур на 10%. Усилители не усиливают друг друга. |
| Картофель | Вокруг, 8 клеток | +2 п. п. к бесплатному отрастанию соседей. Сам картофель имеет собственные 10%. |
| Морковь | Диагонали, 4 клетки | +5% к скорости соседей другого вида. Разнообразие посадок как игровая тема. |
| Огурец | Два шага по вертикали | Дополнительный сбор соседа имеет 10% шанс дать ещё единицу урожая. Образ плети. |
| Томат | Вокруг, 8 клеток | Сам получает +3% урожая за каждый отличный от него вид вокруг. |
| Болгарский перец | Две клетки по горизонтали | Получает и передаёт +5% скорости за соседство с томатом или баклажаном. Игровой образ общего микроклимата. |
| Баклажан | Крест, 4 клетки | При полностью влажных соседях сам получает +20% урожая; в ответ соседи получают +5%. |
| Белокочанная капуста | Вокруг, 8 клеток | Соседи получают +10% удержания влаги. В будущем защищает от одного эпизода стресса за цикл. |
| Цветная капуста | Диагонали через одну клетку | Если все четыре доступных места заняты разными видами, +25% шанса мутации в пустых соседних клетках. |
| Сельдерей | Вся строка и столбец | 3% шанс повторить сработавшую способность. Повтор не запускает следующий повтор. |

Реальная основа наиболее прямая у азотфиксации бобовых, затенения почвы широкими листьями и рационального смешанного размещения. Конкретные проценты, формы аур, отрастание соседних видов и повтор способностей — игровые допущения. Обобщённые заявления об отпугивании вредителей любым чесноком требуют осторожности.

До реализации надо выбрать правила суммирования одинаковых аур, исключить рекурсивные усиления и показать область при наведении.

## Личные способности культур — на согласование

Соседство отложено. Ниже эффекты самого растения, пригодные для наследования. Реализованы пока только скорость редиса и отрастание картофеля. Остальные числа — предложения.

| Вид | Способность | Начальная сила |
|---|---|---|
| Редис | Скороспелость — ускорение собственного роста | +5% |
| Салат | Второй срез — шанс дополнительно собрать урожай без расхода семян; новый цикл роста | 4% |
| Кабачок | Обильный урожай — шанс удвоить количество при сборе | 3% |
| Горох | Семенной запас — шанс вернуть дополнительное семя этой же линии при сборе | 5% |
| Свёкла | Сахаристость — повышает цену продажи плодов | +8% |
| Лук | Запас влаги — полив действует дольше | +10% |
| Чеснок | Устойчивость — снижает сопротивление селекции при проверке мутации | 1 пункт |
| Картофель | Отрастание — начинает новый цикл без расхода семени | 5% |
| Морковь | Крепкий корень — медленный рост продолжается в сухой земле | 10% обычной скорости |
| Огурец | Ранний сбор — шанс сразу завершить последние 10% роста | 5% за цикл |
| Томат | Дозревание — после созревания растёт бонус цены, пока плод не собран | +1% за минуту, до +20% |
| Перец | Концентрат — увеличивает количество семян при извлечении из плода | +10% |
| Баклажан | Теплолюбие — быстрее растёт при ясной погоде | +8% |
| Белокочанная капуста | Плотный кочан — увеличивает размер каждого успешного бонуса урожая | +10% |
| Цветная капуста | Изменчивость — повышает шанс удачного генетического сдвига у потомства | +2 п. п. |
| Сельдерей | Возобновление — шанс получить урожай и оставить растение с половиной пройденного роста | 3% |

Для полноценного салата и гороха нужно хранение генотипа в плодах/возвращаемых семенах. Для свойств продажи и извлечения требуется отдельный склад плодов линий. Эти зависимости нужно реализовать перед включением соответствующих способностей.

## Обсуждение личных способностей

Одобрены редис, кабачок, свёкла, лук, чеснок, картофель, морковь, баклажан, цветная капуста и сельдерей. Предложения для уточнения:

- Салат: «Дружные всходы» — при посадке 5% шанс сразу начать с 20% прогресса роста.
- Горох: «Семенной запас» означает дополнительное семя той же линии при сборе; можно переименовать в «Стручок» и давать фиксированный шанс +2 семени.
- Огурец: каждые 30 секунд активного роста 1% шанс убрать половину оставшегося времени. Усиление свойства повышает шанс, не частоту проверок.
- Томат: после созревания дорожает каждый игровой минутный интервал. Первые две минуты без риска. С третьей минуты перед очередной прибавкой проверяется гниль: 0,1%, 0,2%, 0,4%, 0,8% и далее с удвоением, максимум 100%. До +2% к цене за минуту как стартовый баланс. Усиление повышает прибавку цены, риск остаётся прежним.
- Перец: «Острый старт» — 3% шанс после полива получить ускорение ×2 на первые 30 секунд роста. Возможно слишком близко к скорости, требуется согласование.
- Капуста: «Крупный кочан» — каждый дополнительный успех каскада даёт +1 урожая вместо исходной прибавки; альтернативно 5% шанс при сборе получить ещё один полный базовый урожай. Варианты пока открыты.

Новые способности пока не включены в механику.
Уточнение обсуждения: салат, огурец и крупный кочан одобрены. Горох пока допустим за счёт ограничения в три свойства. Перец должен сохранять ценность после автоматизации полива; предложен «Катализатор» — усиление двух других свойств этого растения, без самоусиления. Для томата обсуждается отдельная наследуемая стабильность: коэффициент изменения риска может снижаться от 2 к 1, затем ниже 1, но сам шанс всегда остаётся в диапазоне 0–100%. Это пока проект.
Текущее уточнение: Re — селекционный потенциал, 1–30, больше лучше. Способность чеснока повышает эффективное Re на проверке.
